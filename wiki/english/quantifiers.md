# Cuantificadores (Quantifiers)

Un **quantifier** indica cantidad de forma imprecisa (a diferencia de los números, que la indican de forma exacta). La elección del cuantificador correcto depende de si el sustantivo que modifica es **countable** (contable) o **uncountable** (incontable) — ver [[wiki/english/nouns/countable-uncountable-nouns.md|Sustantivos Contables e Incontables]]. Esta concordancia obligatoria es uno de los puntos más probados del TOEFL Structure.

## Tabla maestra de concordancia

| Cuantificador | Con contables (plural) | Con incontables |
|---|---|---|
| *many* | ✓ *many books* | ✗ |
| *much* | ✗ | ✓ *much information* |
| *a few* / *few* | ✓ *a few students* | ✗ |
| *a little* / *little* | ✗ | ✓ *a little time* |
| *fewer* | ✓ *fewer errors* | ✗ |
| *less* | ✗ | ✓ *less money* |
| *a number of* | ✓ *a number of complaints* | ✗ |
| *a great deal of* / *a large amount of* | ✗ | ✓ *a great deal of effort* |
| *several* | ✓ *several options* | ✗ |
| *a couple of* | ✓ *a couple of books* | ✗ |
| *a bit of* | ✗ | ✓ *a bit of sugar* |
| *some / any* | ✓ | ✓ |
| *a lot of / lots of* | ✓ | ✓ |
| *plenty of* | ✓ | ✓ |
| *no / none of* | ✓ | ✓ |
| *all / most* | ✓ | ✓ |

> **Regla de oro:** *many, few, fewer, a number of, several* → siempre contable plural. *Much, little, less, a great deal of* → siempre incontable. *Some, any, a lot of, plenty of* → funcionan con ambos.

## much / many

*Many* se usa con sustantivos contables plurales; *much* con incontables. En inglés formal escrito (el registro que evalúa el TOEFL), ambos se usan en afirmativas, negativas e interrogativas por igual — la restricción de "much/many solo en negativas e interrogativas" es una simplificación de nivel conversacional que **no aplica** en Written Expression.

> *Many* researchers have studied this phenomenon. ✓ (formal, afirmativa)
> *Much* controversy surrounds the new policy. ✓ (formal, afirmativa)

## few / a few — little / a little

La presencia o ausencia del artículo cambia completamente el significado: **con "a" es cantidad positiva** ("algo, aunque poco"); **sin "a" es cantidad negativa/insuficiente** ("casi nada").

| Expresión | Connotación | Ejemplo |
|---|---|---|
| *a few* (contable) | Positiva: "algunos, unos cuantos" | *I have **a few** friends who can help.* (suficientes) |
| *few* (contable) | Negativa: "pocos, casi ninguno" | ***Few** students passed the exam.* (insuficiente, preocupante) |
| *a little* (incontable) | Positiva: "un poco, algo de" | *There's **a little** milk left — enough for coffee.* |
| *little* (incontable) | Negativa: "poco, casi nada" | ***Little** progress has been made.* (insatisfactorio) |

## fewer / less

*Fewer* modifica contables; *less* modifica incontables. Es el error de concordancia más señalado en inglés estándar, incluso entre hablantes nativos, y el TOEFL lo aprovecha específicamente.

> *There are **fewer** cars on the road today.* (contable)
> *There is **less** traffic on the road today.* (incontable)

**Excepción memorizada:** con expresiones de medida, distancia, dinero o tiempo tratadas como una unidad total (no como elementos individuales), se usa *less* aunque el sustantivo sea gramaticalmente contable:

> *The trip took **less** than three hours.* (no *fewer than three hours*)
> *She weighs **less** than 50 kilograms.*

## some / any

Ambos funcionan con contables e incontables. La distinción no es de tipo de sustantivo sino de **polaridad de la oración**.

| Contexto | Cuantificador | Ejemplo |
|---|---|---|
| Afirmativa | *some* | *I have **some** questions.* |
| Negativa | *any* | *I don't have **any** questions.* |
| Interrogativa (neutra) | *any* | *Do you have **any** questions?* |
| Interrogativa (oferta/petición, se espera "sí") | *some* | *Would you like **some** coffee?* |
| Condicional | *any* | *If you have **any** doubts, ask.* |

## a lot of / lots of / plenty of

Funcionan con ambos tipos de sustantivo y son intercambiables entre sí en registro informal a semiformal. En escritura académica muy formal se prefieren *many/much* o *a number of / a great deal of*.

> *A lot of* evidence supports this theory. (incontable)
> *Lots of* students attended the lecture. (contable)

## a number of vs. the number of

Distinción de concordancia verbal (ver también [[wiki/english/pronoun-agreement.md|Pronombre: Concordancia y Referencia]]):

| Expresión | Concordancia | Ejemplo |
|---|---|---|
| *a number of* + plural | Verbo plural | *A number of employees **are** unhappy.* |
| *the number of* + plural | Verbo singular (el sujeto real es "the number") | *The number of employees **is** increasing.* |

## Formas coloquiales

Además de las formas neutras, existen variantes informales de uso frecuente en el habla:

| Con ambos tipos | Solo contables |
|---|---|
| *plenty of, loads of, tons of, heaps of, a load of* | *a couple of, hundreds of, thousands of* |

> Se recomienda evitarlas en escritura formal/académica; en TOEFL Written Expression se prefieren las formas neutras (*many, much, a lot of*).

## Every / each

Ambos significan "todos" y se usan con sustantivo **singular**, sin determinante adicional: ***Every** shop was decorated.* (no *the every shop*). Ver la diferencia de matiz y concordancia entre *each* y *every* en [[wiki/english/subject-verb-agreement.md|Subject-Verb Agreement]].

## Both / either / neither

Se usan para hablar de **dos** personas o cosas, y cada uno exige una concordancia verbal distinta:

| Cuantificador | Concordancia | Ejemplo |
|---|---|---|
| *both* | Verbo plural | *Both the supermarkets **were** closed.* |
| *either* | Verbo singular | *Either supermarket **is** fine.* |
| *neither* | Verbo singular | *Neither of the supermarkets **was** open.* |

## Grupo general vs. grupo específico

Cuando el cuantificador (*few, many, some*…) se refiere a un grupo **general**, no lleva *of the*; cuando se refiere a un grupo **específico** ya delimitado, sí lo requiere:

> ***Few** snakes are dangerous.* (afirmación general sobre las serpientes)
> ***Few of the** snakes in this zoo are dangerous.* (grupo específico: las serpientes de este zoológico)

## Errores frecuentes (TOEFL)

*many/much con el tipo de sustantivo equivocado:*

| ✗ Incorrecto | ✓ Correcto |
|---|---|
| *She doesn't have **much** friends in the city.* | *She doesn't have **many** friends in the city.* |

"Friends" es contable plural → exige *many*, no *much*.

*fewer/less invertidos:*

| ✗ Incorrecto | ✓ Correcto |
|---|---|
| *The new policy resulted in **less** complaints from customers.* | *The new policy resulted in **fewer** complaints from customers.* |

"Complaints" es contable plural → *fewer*, no *less*. Este es probablemente el error de cuantificadores más probado en el TOEFL.

*a number of / the number of con concordancia verbal incorrecta:*

| ✗ Incorrecto | ✓ Correcto |
|---|---|
| *A number of scientists **has** questioned the results.* | *A number of scientists **have** questioned the results.* |
| *The number of accidents **have** decreased significantly.* | *The number of accidents **has** decreased significantly.* |

*little/few sin artículo cuando se quiere connotación positiva:*

| ✗ Incorrecto | ✓ Correcto |
|---|---|
| *Don't worry, we have **little** time to finish — we can make it.* | *Don't worry, we have **a little** time to finish — we can make it.* |

Sin "a", *little* connota "casi no hay tiempo" (negativo), lo cual contradice el tono optimista de la oración.

*much/many con sustantivo incontable tratado como si fuera contable:*

| ✗ Incorrecto | ✓ Correcto |
|---|---|
| *The professor gave us **many** advice on how to study.* | *The professor gave us **much/a lot of** advice on how to study.* |

"Advice" es incontable en inglés (aunque "consejo" sea contable en español) — exige *much* o *a lot of*, nunca *many*.
