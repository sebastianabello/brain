# Sustantivos Plurales (Plural Nouns)

Un **plural noun** refiere a más de una unidad de algo (frente al singular, que refiere a una sola)[^1]. Lo normal es formarlo añadiendo **-s** al singular (*cat → cats*), pero ciertas terminaciones exigen cambios, y hay plurales irregulares que no terminan en *-s*.

## Plurales regulares

| Terminación | Regla | Ejemplos |
|---|---|---|
| (general) | añadir **-s** | dog → dogs; house → houses; Monday → Mondays |
| ch, sh, ss, x | añadir **-es** | church → churches; wish → wishes; tax → taxes |
| f, fe | normalmente **-s**, a veces **f/fe → -ves** | belief → beliefs; wolf → wolves; life → lives |
| o | tras vocal, **-s**; tras consonante, suele **-es** (con excepciones) | cuckoo → cuckoos; tomato → tomatoes; piano → pianos |
| s, z | añadir **-es** (a veces se dobla la consonante) | gas → gases; quiz → quizzes |
| consonante/u + y | **y → -ies** | city → cities; spy → spies; soliloquy → soliloquies |
| vocal + y | añadir **-s** | day → days; ploy → ploys |

## Plurales irregulares

Restos de formas antiguas del inglés o préstamos de otros idiomas. Son pocos, pero muy frecuentes.

| Grupo | Ejemplos |
|---|---|
| Plural antiguo en **-en** | child → children; ox → oxen; brother → brethren (solo en contextos religiosos) |
| **Cambio de vocal** interna | foot → feet; goose → geese; man → men; mouse → mice; tooth → teeth |
| Latín/griego (conservan su forma) | analysis → analyses; appendix → appendices; fungus → fungi; phenomenon → phenomena |
| Otros idiomas (a veces alternan con el plural inglés) | bureau → bureaux/bureaus; cherub → cherubim/cherubs |
| **Igual** en singular y plural | bison; fish; series; sheep; species |
| Otros irregulares | die → dice; penny → pence; person → people |

> Algunos plurales latinos se tratan ya como singulares en inglés (*media*, *data*); otros adoptaron plural inglés (*stadiums* > *stadia*). El plural correcto de *octopus* es **octopuses** (no *octopi*; el griego original sería *octopodes*).

## Plurales de sustantivos compuestos

Para pluralizar un compuesto, se pluraliza la palabra que es el **"núcleo"** (head): la cosa representada, que las demás modifican.

- Núcleo al final → *high **schools*** (muchas escuelas, no muchos *highs*).
- Núcleo antes → ***heads** of state*.
- Ocasionalmente varias → *men-children*.

## Error común: el apóstrofo

Los apóstrofos forman [posesivos](wiki/english/nouns/possessive-nouns.md) y contracciones, **no plurales**. Tampoco se necesita para pluralizar números, siglas o nombres propios.

- ❌ *the 1980's* → ✅ *the 1980s*
- ❌ *SUV's* → ✅ *SUVs*
- ❌ *the Jones's* → ✅ *the Joneses*

Única excepción: pluralizar una **letra suelta** sí lleva apóstrofo, para evitar confusión (*a's* vs. *as*). *Write "accommodation" with the right number of **c's** and **m's**.*

## Casos especiales

- **Plural en forma, singular en construcción**: nombres de campos de estudio (*physics*, *mathematics*, *ethics*) y otros (*news*, *measles*, *billiards*) parecen plurales pero llevan verbo singular. *The good **news** is…* — *Ethics **is** the most fascinating branch of philosophy.*
- **Nouns siempre plurales (*plurale tantum*)**: cosas formadas por un par (*scissors*, *pants*, *glasses*, *pliers*, *tongs*). No tienen singular ni admiten artículo indefinido; se usa *a pair of* / *pairs of*. *The scissors **are** over there.* — *three **pairs of** pants*.

## Plurales y sustantivos incontables

Los [sustantivos incontables](wiki/english/nouns/countable-uncountable-nouns.md) (*mass nouns*) no tienen plural ni admiten *a/an*. Para cuantificarlos se usa una unidad de medida o una alternativa: ❌ *several researches* → ✅ *several pieces of research* / *several studies*; ❌ *70 waters* → ✅ *70 ml of water*.
