# Orden de los Adjetivos en Inglés

## Regla principal
Orden estándar con múltiples adjetivos: cantidad, valor/opinión, tamaño, temperatura, edad, forma, color, origen, material.

## Categorías detalladas
| Categoría | Ejemplos |
|---|---|
| Cantidad | four, ten, a few, several |
| Valor/Opinión | delicious, charming, beautiful |
| Tamaño | tall, tiny, huge |
| Temperatura | hot, cold |
| Edad | old, young, new, 14-year-old |
| Forma | square, round |
| Color | red, purple, green |
| Origen | Swedish, Victorian, Chinese |
| Material | glass, silver, wooden |

## Ejemplos textuales
- "They have a lovely old red post-box" — cantidad (implícita), opinión (lovely), edad (old), color (red)
- "The playroom has six small round plastic tables" — cantidad, tamaño, forma, material
- "some charming Victorian silver ornaments" — opinión, origen, material
- "flashy 3-year-old Italian car" — opinión, edad específica, origen
- "beautiful cold day" — opinión, temperatura

## Matiz importante
No todos estos adjetivos deben aparecer juntos necesariamente; cuando varios coinciden, deben respetar este orden secuencial.
